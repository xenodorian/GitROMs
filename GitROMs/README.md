# GitROMs

Simple GitHub ROM browser for R36S (ArkOS).

No browser. No system changes. Just Python + pygame.

## How to install

1. Unzip this folder into the **ports** folder on your SD card.
2. Put the SD card back in the R36S and turn it on.
3. Go to **Ports** and open **GitROMs**.

That is all.

## Controls

- D-pad = move
- A = select / download
- B = back

## Notes

- Downloads go into the correct system folders under your roms partition.
- Needs Wi-Fi only when browsing/downloading from GitHub.
- If it fails, look at the file `gitroms.log` next to the app.
